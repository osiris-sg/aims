AIMS is a multi-tenant business platform built for Osiris Technology and its client organizations (Biofuel Industries, Cappitech, and others). It started as an asset/inventory/document system and has grown into a full ERP surface: sales documents, double-entry accounting with Xero parity, AI assistants, field-tech mobile flows, and external integrations.

## The four deployables

| Deployable | Stack | Deploys to |
|---|---|---|
| `api-server-production/` | NestJS 10, Prisma 6, PostgreSQL (Neon) | Render (`aims` prod, `aims-staging`) |
| `portal-production/` | Next.js 14 App Router, MUI v6, Clerk | Vercel (`www.ai-ms.io`; previews at `aims-mocha.vercel.app`). Also ships a Capacitor Android field app |
| `email-ingest-worker/` | Cloudflare Email Worker | Cloudflare — routes `docs+{orgId}@…` mail to the ingestion webhook |
| `whatsapp-group-bridge/` | Node + `whatsapp-web.js` | Standalone worker — bridges WhatsApp *group* messages (groups aren't on Meta's Cloud API) |

  <Card title="AI assistants" icon="sparkles" href="/backend/modules-ai">

  </Card>
  <Card title="Integrations" icon="plug" href="/backend/integrations">
